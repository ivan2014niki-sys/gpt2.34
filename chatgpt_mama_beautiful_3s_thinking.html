Распознавание музыки · AudD

Токен не введён

Нужен только для запроса «определи песню по этому аудио». Токен AudD не заменяет и не меняет ключи Lenec или AI FunPay; он хранится только в текущей вкладке. Стандартный endpoint AudD принимает аудиофайлы до 10 МБ.

Модели и адрес API уже настроены. Ответы выводятся постепенно по мере поступления токенов (streaming). Также доступны вложения в чате, озвучивание ElevenLabs и интернет-поиск, если Lenec поддерживает web_search.

Модель GPT 5.6 Sol использует отдельный ключ AI FunPay. Остальные модели основного чата продолжают использовать Lenec.

О ключе: он встроен в HTML в обфусцированном виде, без пароля и без запроса пароля при запуске. Это только маскировка от случайного просмотра, а не надёжное шифрование: человек, который изучит исходный код или инструменты браузера, сможет восстановить ключ. Для настоящей защиты нужен серверный посредник, где ключ хранится только на сервере.

Озвучивание: используется выбранный голос ElevenLabs или Yandex SpeechKit из меню голосов. Микрофон распознаёт речь средствами браузера; для микрофона нужна HTTPS-страница или localhost.

Рекомендация: ключи, отправленные в переписке и встроенные в HTML, следует считать раскрытыми. Обфускация мешает только случайному просмотру, но не защищает от извлечения. Для настоящей защиты храните ключи на сервере.

Выбор голоса

Выбери голос по имени и описанию. Нажми «Послушать», чтобы сравнить звучание, затем «Выбрать». Идентификаторы голосов здесь не показываются.

Голоса Rachel, Sarah, Alice, Adam, Brian, Liam и George — готовые пресеты. Также сохранён твой текущий голос.
Для реального прослушивания Yandex SpeechKit нужны учётные данные Yandex Cloud. Введённые данные остаются только в памяти этой вкладки и не встраиваются в HTML.

Yandex API v1: выбранный голос синтезируется как русский (ru-RU). Для API-ключа сервисного аккаунта ID каталога в запрос не передаётся; для IAM-токена он обязателен.
